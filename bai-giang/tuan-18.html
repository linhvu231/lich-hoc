Bước 1: Trên từng thiết bị (R1, R2, SW1)

(config)# hostname <tên>
(config)# ip domain-name lab.local
(config)# crypto key generate rsa modulus 2048
(config)# ip ssh version 2
(config)# username admin privilege 15 secret <mật-khẩu-lab>
(config)# aaa new-model
(config)# aaa authentication login default local
(config)# aaa authorization exec default local
(config)# ip access-list standard MGMT
(config-std-nacl)# permit 10.99.0.0 0.0.0.255
(config)# line vty 0 15
(config-line)# transport input ssh
(config-line)# access-class MGMT in
(config-line)# exec-timeout 10 0
(config)# login block-for 120 attempts 5 within 60

Phần A · MOP #14: chuyển toàn lab sang SSH-only

# MOP-014 · Chuyển R1, R2, SW1 sang SSH-only, AAA local

| Mục        | Nội dung                                                      |
|------------|---------------------------------------------------------------|
| Mục tiêu   | Không còn telnet; đăng nhập bằng user riêng; chỉ dải MGMT vào  |
| Phạm vi    | line vty, AAA, ACL MGMT trên 3 thiết bị                        |
| Ảnh hưởng  | Phiên telnet đang mở sẽ không mở lại được                     |
| Rủi ro     | Tự khóa mình (AAA sai, ACL MGMT sai dải) ⇒ chuẩn bị console    |

## 1. Pre-check
- Có đường console tới từng thiết bị (trong lab: cửa sổ console CML/EVE)
- show ip ssh ; show running-config | section line vty   ! lưu bản trước
- copy running-config flash:pre-mop014.cfg

## 2. Các bước (từng thiết bị, giữ phiên hiện tại mở)
1. reload in 10                          ! lưới an toàn
2. hostname, ip domain-name, crypto key, ip ssh version 2
3. username admin privilege 15 secret …  ! TẠO USER TRƯỚC
4. aaa new-model ; aaa authentication login default local
5. ip access-list standard MGMT ; line vty 0 15 ; transport input ssh ; access-class MGMT in
6. MỞ PHIÊN SSH MỚI từ MGMT-PC ⇒ đăng nhập được thì: reload cancel ; write memory

## 3. Verify
- ssh được từ MGMT-PC; telnet bị từ chối; SSH từ PC10 bị từ chối
- show ip ssh: version 2.0 ; show users: phiên SSH của admin

## 4. Rollback
- Nếu không vào được phiên mới: đợi reload in 10 (về cấu hình đã lưu), hoặc vào console:
  configure replace flash:pre-mop014.cfg

Phần B · Sự cố: tự khóa mình ngoài thiết bị do sai AAA

Trên R2 (chỉ trong lab), cố tình làm sai theo thứ tự:

R2(config)# no username admin                                   ! hoặc "quên" tạo user
R2(config)# aaa new-model
R2(config)# aaa authentication login default group tacacs+      ! không có server, không có "local"
R2(config)# end
R2# write memory
! thoát phiên, thử SSH lại và thử console
Gợi ý khôi phục (mở sau khi làm)
  1. SSH: "Access denied". Console cũng hỏi Username và từ chối (vì login default áp cho cả console).
  2. Cách 1 (nếu còn một phiên đang mở ở đâu đó): sửa ngay aaa authentication login default group tacacs+ local, tạo lại user.
  3. Cách 2: password recovery qua console: reload, ngắt (Break) vào ROMMON, confreg 0x2142 (bỏ qua startup-config), reset; vào router, copy startup-config running-config, sửa AAA + user, config-register 0x2102, write memory, reload.
  4. Switch Catalyst: giữ nút Mode khi bật nguồn, dùng flash_init và đổi tên config.text (theo tài liệu của từng dòng).
  5. Phòng ngừa: luôn có local cuối danh sách, user local trước, reload in, kiểm bằng phiên mới. Ở công ty: một tài khoản local "break-glass" lưu trong két mật khẩu.

Chủ nhật (07/03) · Bài JSON lồng nhau, tự kiểm tra, tự chấm

1,5 giờĐầu ra: 5 câu trả lời JSON đúng (đầu ra trong lịch), 5 mức tự chấm

Bài JSON (làm ra giấy trước, rồi kiểm bằng jq)

{
  "site": "chi-nhanh-lab",
  "devices": [
    { "name": "r1", "role": "router",
      "interfaces": [ {"name": "g0/0", "ip": "10.99.0.1", "up": true},
                      {"name": "g0/1", "ip": null,        "up": false} ] },
    { "name": "sw1", "role": "switch",
      "vlans": [10, 20, 99],
      "interfaces": [ {"name": "g0/1", "up": true, "trunk": true} ] }
  ]
}
1. devices[0].interfaces[1].up ?

false.

2. devices[1].vlans[2] ?

99 (đếm từ 0).

3. Có bao nhiêu thiết bị? Lệnh jq?

2. jq '.devices | length'.

4. IP của g0/1 trên r1?

null (không có IP).

5. Lệnh jq in tên mọi interface đang up kèm tên thiết bị?

jq -r '.devices[] | .name as $d | .interfaces[] | select(.up) | "\($d) \(.name)"' ⇒ "r1 g0/0" và "sw1 g0/1".

Câu hỏi tự kiểm tra trong lịch

1. Bật SSH trên Cisco cần 4 thứ gì?

Hostname, domain name, khóa RSA, user local + login local/transport input ssh trên vty.

2. RADIUS và TACACS+ khác nhau ở 2 điểm nào?

UDP vs TCP 49; RADIUS chỉ mã hóa mật khẩu, TACACS+ mã hóa toàn bộ (và tách A-A-A).

3. DHCP snooping: port nào đặt trusted?

Uplink về phía DHCP server thật.

4. DAI cần tính năng nào chạy trước?

DHCP snooping.

5. WPA3 Personal thay PSK bằng gì?

SAE.

6. Mã HTTP 401 nghĩa là gì?

Unauthorized: chưa xác thực hoặc token sai/hết hạn.

7. Trong JSON mẫu, interfaces[0].up có giá trị gì?

true.
