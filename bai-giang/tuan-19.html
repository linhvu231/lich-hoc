# MOP-015 · Dựng chi nhánh mới (mẫu dùng lại)

| Mục        | Nội dung                                                         |
|------------|------------------------------------------------------------------|
| Mục tiêu   | Chi nhánh có LAN dự phòng, định tuyến động, Internet, phân vùng khách |
| Phạm vi    | R-BR, DSW1, DSW2, ASW1 (+ ISP, Zabbix)                            |
| Đầu vào    | Bảng IP đã duyệt, sơ đồ, danh sách VLAN, thông tin đường ISP     |
| Rủi ro     | Trùng dải với nơi khác; NAT/ACL sai làm mất dịch vụ; khóa mình khi bật AAA |

## 0. Chuẩn bị
- Kiểm dải 10.10.0.0/16 chưa dùng ở đâu (IPAM / bảng IP chung)
- Console tới mọi thiết bị; file cấu hình soạn sẵn theo bảng IP

## 1. Các khối (mỗi khối: cấu hình → verify → ghi kết quả)
1. Cơ bản: hostname, VLAN, mô tả cổng            → show vlan brief
2. Tầng 2: trunk, Po1, STP root, PortFast/BPDU    → show interfaces trunk / etherchannel summary / spanning-tree root
3. Gateway: SVI, HSRP (khớp STP root)            → show standby brief
4. Routing: routed link, OSPF, default            → show ip ospf neighbor / show ip route
5. Dịch vụ: DHCP pool, helper                     → show ip dhcp binding
6. Internet: NAT                                  → show ip nat translations
7. Bảo mật: ACL GUEST, SSH/AAA, MGMT ACL          → show access-lists, thử SSH phiên mới
8. Vận hành: NTP, timestamps, Syslog, SNMP, Zabbix → show ntp status, host xanh trên Zabbix

## 2. Nghiệm thu
- Checklist verify sổ tay mục 5 đạt 100%
- Failover: tắt DSW1 rồi DSW2, ghi số gói mất
- Lưu cấu hình, sơ đồ as-built, bàn giao

## 3. Rollback
- Chi nhánh mới chưa có người dùng: xóa trắng và dựng lại từ file cấu hình
- Từng khối: gỡ đúng lệnh của khối đó (ghi sẵn lệnh "no …" cạnh mỗi khối)

Nhờ người khác gài, hoặc tự viết 5 lỗi lên 5 mẩu giấy, úp lại, bốc ngẫu nhiên. Mỗi lần chỉ gài một lỗi trên baseline, bấm giờ từ lúc nghe triệu chứng đến lúc sửa xong và verify. Sau mỗi lỗi, khôi phục baseline.

Danh sách lỗi để gài (người gài mở; người sửa mở sau khi xong)
  1. ASW1 thiếu VLAN 20: no vlan 20 trên ASW1 ⇒ Gi0/3 inactive. Phát hiện: show interfaces g0/3 switchport ("Access Mode VLAN: 20 (Inactive)"), show vlan brief.
  2. HSRP lệch STP root: trên DSW1 no standby 10 preempt, rồi reload DSW1 ⇒ DSW2 active VLAN 10 trong khi STP root VLAN 10 vẫn là DSW1. Phát hiện: so show standby brief với show spanning-tree root. Ảnh hưởng: lưu lượng vòng qua Po1, mất tính dự đoán.
  3. OSPF hello mismatch: ip ospf hello-interval 5 trên g0/0 của DSW2 ⇒ DSW2 mất neighbor, mất default route; VLAN 20 (DSW2 active) không ra Internet. Phát hiện: show ip ospf neighbor trên R-BR chỉ còn 2.2.2.2; show ip ospf interface g0/0 hai bên khác timer.
  4. R-BR g0/1 thiếu ip nat inside: no ip nat inside trên g0/1 ⇒ gói từ VLAN 20 (qua DSW2) ra ISP với nguồn 10.10.20.x, ISP không có đường về. Phát hiện: show ip nat translations không có 10.10.20.x; traceroute từ guest đi tới R-BR rồi mất; show ip interface g0/1 | include NAT.
  5. GUEST-IN thiếu dòng permit bootps: no 10 trong GUEST-IN trên cả hai DSW ⇒ Discover (nguồn 0.0.0.0) bị implicit deny. Máy đã có lease vẫn chạy (cho tới khi gia hạn). Phát hiện: hit count không tăng ở dòng nào khi PC mới renew; debug ip dhcp server packet trên R-BR không thấy Discover.
